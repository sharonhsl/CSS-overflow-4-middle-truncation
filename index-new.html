text-overflow: ellipsis middle

This is a minimal demo of the proposed middle ellipsis spec for text overflow handling. The elements are styled by declaring custom CSS property --text-overflow, and truncated according to the spec (with some caveats, e.g. float/scroll not yet implemented).

ℹ️ This demo breaks a truncated text into two parts and apply text-overflow: ellipsis on the prefix.

Syntax

text-overflow = [ [ clip | <overflow-marker> ] && [ start | end ]? ]{1,2} | [ <overflow-marker> && [ middle | <length-percentage> ] ]; <overflow-marker> = [ ellipsis | <string> | fade | <fade()> ];
